# Reviewed references

This directory is for source material that has been explicitly reviewed and
approved for inclusion in the private repository.

Before adding a file, record it in `MANIFEST.md` and confirm that it:

1. is needed to design, verify, or maintain the Learning Lab;
2. contains no learner- or client-identifiable information;
3. is appropriate to store in a private GitHub repository;
4. has a clear source, retrieval date, and intended use; and
5. is not an unnecessary duplicate or a generated export.

Prefer links and page-level citations over storing large source binaries when
the original is publicly accessible and stable.
